# Claim-to-file map

Every number reported in the paper and the file that produces it. Every row
resolves to a file in this package.

Table II is regenerated by

    python scripts/score_validation.py \
        data/detector_validation_labelled.xlsx state/nb7_validation_key.json

which reproduces every figure in it, including the per-class intervals, the
two agreement rows with their kappas, and the 0.915 pooled figure the text
quotes for counting all 100 flagged files.

## Three notes on provenance

`notebooks/NB8_robustness.ipynb` can run either `src/cs_did.py` or a
self-contained fallback. `results/nb8_summary.json` records
`estimator = cs_did.py` for the reported run, so the checks used the same
estimator as the main pipeline. It re-estimates the four BH survivors before
proceeding and records the comparison in `nb8_summary.json`:
`recon_max_att_dev_in_se` = 0.5278 and `recon_max_se_rel_dev` = 0.0829, the
0.53 SE and 8.3% figures quoted in the paper, with the smallest relative
deviation 0.0066. It differs from the main pipeline only in the cohort set it
retains, not in the estimator. Tables IV and V come from
`results/results_main.csv`; Table VI from the NB8 outputs.

**Every parallel-trends statistic in the paper comes from one run**, the
five-outcome test in `results/nb8_r2_pretrends.csv`. Section V-A and Table VI
Panel D both quote its `o1` row, 1.5064 against 2.8200. The file carries the
full z path for each outcome, so any figure in Section V-A or Panel D can be
recomputed from it directly.

Two other pre-trend figures are recorded in this package and are **not** what
the paper reports:

| Source | max abs z | critical value | rejects |
|---|---|---|---|
| `results/nb5_summary.json`, `pretrend` | 1.6405 | 2.7387 | no |
| `results/nb4_summary.json`, `pre_trend_max_abs_z` | 2.0978 | not recorded | - |

`nb5_summary.json` holds the main pipeline's own pre-trend on the primary
outcome. It is a separate estimation from the five-outcome run and estimates
a different path: the same eleven leads give a summed squared z of 11.213
against the reported run's 9.888. Both fail to reject by a wide margin, so
the conclusion does not turn on the choice, and the paper quotes the run that
covers every reported outcome, which is what Section VI-D argues an
identifying-assumption test should do. `nb4_summary.json`'s figure is a
diagnostic from panel construction, computed before the estimation stage.

`results/results_main.csv` carries a `twfe_se` column that is populated only
for the `A_first_gating` rows. Table VI Panel A reports TWFE point estimates
against Callaway-Sant'Anna for all eight outcomes and clustered standard
errors for the primary arm only, which is what the file supports.
